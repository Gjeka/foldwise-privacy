# Foldwise privacy policy and support

The public pages of Foldwise (Foldwise: Unfold Counter), by KGWorks, served with GitHub Pages:

- Privacy policy: https://gjeka.github.io/foldwise-privacy/
- Terms of service: https://gjeka.github.io/foldwise-privacy/terms.html
- Support: https://gjeka.github.io/foldwise-privacy/support.html

They're written in the app's own (private) repository, in `docs/store/privacy-policy.md`, `docs/store/terms.md` and
`docs/store/support.md`, and turned into `index.html`, `terms.html` and `support.html` with
`docs/store/tools/store_page.py`. Change them there,
regenerate the pages, then commit them here.
