# Foldwise privacy policy

The public privacy policy of Foldwise (Foldwise: Unfold Counter), by KGWorks, served with GitHub Pages at
https://gjeka.github.io/foldwise-privacy/.

The policy is written in the app's own (private) repository and turned into `index.html` there with
`docs/store/tools/policy_page.py`. Change it there, regenerate the page, then commit it here.
